# 출시 차단과 후속 변경 제안

이 문서는 2026-10-21 실행에서 확인한 문제와 다음 승인 범위를 제안한다. 추가 구현과 UI 검수는 아직 승인되지 않았다. 원래 공개 출시 범위는 계속 유효하되 아래 조건을 건너뛰지 않는다.

## 국가별 등급

Play IARC 설문 요약에서 호주는 유사 도박으로 18세 이상, 한국은 약물로 15세 이상을 표시했다. 이는 설문 관측값이며 최종 심사 승인이나 한국 배포 허가를 의미하지 않는다. 승인된 13세 이상 대상, 한국을 포함한 모든 가능 국가 목표에 영향을 준다. 등급을 낮추기 위해 사실과 다른 답을 선택하지 않는다.

현재 `opp.wager-table`은 골드60을 걸고 첫눈 날짜를 맞히면260을 받으며 틀리면 판돈을 잃는다. `cond.burnout.enter`에는 약을 사서 버티는 선택과 기억 저하 서술이 있다. `opp.plague-ward`에는 약 달이기와 약값 지원, `world.guild-dispute`에는 술을 사겠다는 대사가 있다.

13세 이상 목표를 유지하는 후속안은 다음과 같다.

- `opp.wager-table`을 상인들의 첫눈 예보 의뢰로 바꾼다. 참가비와 판돈을 없애고 성공 사례금200을 지급한다. 실패 시 금전 손실은 없다. 지능 검사와 나머지 성장 효과, 등장 조건과 ID를 유지하고 두 언어 문구를 함께 바꾼다.
- 번아웃의 유료 약 복용 선택은 같은 비용의 식사와 휴식으로 바꾼다. 질병 구호의 약 관련 서술은 물, 식량과 이불 지원으로 바꾸고 술 약속은 식사 약속으로 바꾼다. 전체 문구를 다시 확인하고 약물 또는 도박에 해당하는 내용을 남긴 채 신고만 바꾸지 않는다.
- 변경된 경제와 두 언어 콘텐츠를 검증하고 IARC를 사실에 맞춰 다시 작성한다. 새 등급을 미리 보장하지 않으며 여전히 목표와 충돌하면 다시 멈춘다.

콘텐츠를 유지하는 대안은 국가별 등급에 맞춰 대상 연령을 바꾸거나 해당 국가를 제외하는 것이다. 두 방법 모두 원래 승인 범위 변경이므로 자동 적용하지 않는다.

## UI 검수 기록

UI1/2에서 제품 소스 snapshot/SHA와 계획 시각을 남기지 못했다. UI3는 `123f271`에 결속됐지만 앞선 두 회차의 결손을 대신하지 못한다. 원래 실패 기록과 실행 로그를 그대로 보존한다. 소급 계획이나 추정 SHA는 쓰지 않는다.

후속 내용 변경을 승인한다면 그 설계와 테스트 계획에 새 후보를 고정하고, 독립 검수자가 개발 환경에서 핵심 기능 전체를 3회 검수하는 범위도 함께 승인받는다. 예상20분이며 별도 유료 이미지 생성과 기기 사용은 포함하지 않는다. 각 회차 전 계획, SHA, 시각, 환경, 격리 저장과 검수자를 기록하고 실제 좌표 입력, 두 언어, 화면 크기별 기능과 사용성 근거를 남긴다. 기존 결손은 역사 기록으로 보존하고, 중앙 계약이 허용하는 기록 방식인지 확인한 뒤 실행한다. 기록 방식이 기존 계약으로 표현되지 않으면 정식 보완 없이 빌드로 진행하지 않는다.

이 승인 요청은 [중앙 개발 정책](https://github.com/seorilabs/.github/blob/main/docs/agent-governance/development-workflow.md#재설계-ui-검수-3회)의 “승인 전에 4회차를 시작하지 않는다”는 규칙에 따른다. 기존 기록을 새 검수로 가장하거나 회차 이름만 바꾸어 상한을 우회하지 않는다.

## 업로드 인증과 SDK

등록된 provisioner identity로 공통 Publisher IAM 정책을 읽으려 했으나 `iam.serviceAccounts.getIamPolicy` 권한 부족으로 거절됐다. Play 앱의 Publisher API 조회 성공과 GitHub WIF 업로드 권한은 별개다. 기존 관리자가 저장소용 WIF 연결을 확인할 수 있는 경로가 필요하다. 새 계정, 정적 API 키와 광범위 권한을 만들지 않는다.

Android에서만 실행되는 UMP 양식과 광고 표시, 닫기 후 게임 복귀는 미검수다. 개발 대역 검사는 실제 SDK와 광고 응답을 확인할 수 없다. 기기 사용은 이번 후속 내용 및 UI 승인에 포함하지 않으며, 후보 AAB와 대상이 준비된 뒤 최소 항목을 소명하고 별도 명시적 승인을 받아야 한다.
