# Android 공개 출시 실행 티켓

사용자가 제공한 계획의 구현을 지시했다. [설계와 인수조건 AC-01부터 AC-09](../design/2026-10-21-android-launch/design.md), 같은 폴더의 L3 테스트 계획, [출시 원장](../06-release/2026-10-21-android-launch.md)을 따른다.

## 구현

서버 SDK와 GA4 전송 및 미사용 계측 버스를 제거했다. 기존 로컬 저장을 유지하며 ko/en stable-ID 번역, 언어와 연령 설정, 광고 개인정보 설정, 저장 실패 재시도를 추가했다. 실제 Android SDK는 광고 어댑터 안에 두고 표시 시점과 상한은 로컬 정책으로 검사한다.

실제 시작 장면의 좌표 입력, 드래그, 36턴, 엔딩, 재시작과 저장 복원, 저장 실패와 원본 보존, 광고 실패 및 동의 경계를 E2E에 연결했다. 테스트 저장과 시계는 격리한다. 첫 import부터 로그 오류를 검사하며 예열 실패를 무시하지 않는다.

## 검증과 남은 조건

번역 정적 완전성, 코어 경계, 콘텐츠 정적 검사와 통합 사전검사는 통과했다. 사전 실행을 최종 후보의 L3 증거로 대신하지 않는다. UI 검수 1회차의 영어 카드 넘침, 2회차 영어720 드래그 실패를 보존하고 최종 3회차에서 수정 결과를 검증한다. 회차를 추가하지 않는다.

광고 어댑터의 연령 변경, UMP 비동기 응답과 UTC 자정 노출을 개발 경계에서 재현해 고쳤다. 대체 native singleton 테스트는 Android SDK 실제 표시 근거가 아니다.

최종 SHA의 fresh 검증 2회, 6개 렌더링 여정, 확인된 CI, 중앙 before-build 검증, 서명 AAB 및 마켓 단계는 각각 실제 완료 후 근거를 추가한다. 기기 접근은 하지 않았다.

과거 엔딩 hint와 현재 requirements 숫자 차이는 기존 콘텐츠의 설명 문제다. 현재 UI는 hint를 표시하지 않고 판정은 requirements를 사용한다. 이번 번역은 원문을 보존했으며 숨겨진 hint를 현재 수치에 맞췄다고 주장하지 않는다.
