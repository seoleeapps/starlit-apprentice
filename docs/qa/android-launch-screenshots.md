# Android 등록 화면

`play-store/screenshots/phone/ko/`와 `en/`은 실제 Godot 4.7.2 입력 여정의 720x1280 렌더링 PNG다. 저장은 격리한 가상 진행이고 광고 경계만 대체했다. 원본 그림을 새 UI처럼 합성하거나 크기를 바꾸지 않았다.

타이틀, 행동 카드 스크롤, 월말 결과, 이벤트와 엔딩을 캡처했다. 생성 근거는 독립 UI 검수 2회차 `build/qa/ui-round2-{ko,en}/journey.json`이며, 최종 후보의 3회차와 CI 화면 비교는 별도로 기록한다. 2회차 영어720의 첫 드래그 검사 실패는 보존하며 이 PNG만으로 회차 전체 통과를 주장하지 않는다.

기존 phone 루트와 tablet-7, tablet-10의 픽셀 화면은 과거 웹 클라이언트 자료라 현재 등록 목록에서 제외했다. 현재 태블릿 화면 촬영은 미실행이다. Play 업로드는 아직 하지 않았다.
