# 승인 설계 목록

- [2026-10-21 Android 공개 출시](2026-10-21-android-launch/design.md): 사용자가 계획 구현과 공개 출시를 지시했다. L3 개발 전체 회귀, Android 광고 SDK 필수 검수는 기기 사용 승인 후 별도 실행한다. 테스트 계획은 같은 폴더에 둔다. 실행은 docs/06-release에 연결한다.
- [2026-10-22 Android 산출물 검사 도구 보완](2026-10-22-android-inspector-repair/design.md): 사용자 승인, 실행 티켓[#58](https://github.com/seoleeapps/starlit-apprentice/issues/58). 제품과 UI 파일을 유지하고 새 후보에서 L3 개발 환경 전체 회귀1회를 실행한다. 기존 UI12~14의 완료 기록과 첫 서명 빌드 실패를 보존한다. 추가 UI 회차와 기기 사용은 포함하지 않는다.
