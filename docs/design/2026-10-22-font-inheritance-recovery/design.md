# 실제 시작 장면의 폰트 상속 보완

## 목적과 승인

사용자는 2026-10-22T00:20:30Z에 기기를 사용하지 않는 폰트 보완과 독립 전체 검수12~14회를 승인했다. 승인 제안 v2의 SHA256은 `f28311846aeaded277acc1e3c2f4625d4288ad0835d3da91d5e9730bb71103af`다. 실행 티켓은 [#57](https://github.com/seoleeapps/starlit-apprentice/issues/57)이다. 기존 Android 무료 공개 출시 범위를 유지하며, 이 승인은 기기 사용을 포함하지 않는다.

원 후보는 `0235a8b8ff0530d3d94de3bd511070785620a0f3`이다. UI11은 실제 전체 실행과 화면 검수를 마쳤으나 한글 출력과 사용성에 실패했다. 자동220시나리오 통과를 화면 통과로 해석하지 않는다. 실패 review SHA256은 `c73c94265ee002867a5684b13f029b9cf7ba5f329e0bb41e7400a104ecc8db60`이며 원본783파일과 외부 백업은 일치한다.

## 화면 근거와 변경 범위

[실패 CI39634390141](https://github.com/seoleeapps/starlit-apprentice/actions/runs/39634390141)의 `render-ko-640x1136/01-title.png`에서 제목과 버튼이 네모 글리프로 표시됐다. 한국어 세 화면 크기와 영어에서 한국어로 바꾼 보호 안내에 같은 문제가 있다. 기존 CI39621403005의 대응 두 PNG도 바이트 단위로 같다. 일반 Android 화면에도 발생한다고 단정하지 않는다.

기존 `autoload/ui.gd`는 Window에 Pretendard 테마를 붙인다. E2E는 실제 Main을 별도 SubViewport 아래에 넣는다. [공식 Theme 문서](https://docs.godotengine.org/en/4.7/classes/class_theme.html)는 연속 Control 경로를 통한 테마 상속을 설명한다. 구현자 원인 분리 검사에서 일반 Window 아래 Main의 실제 폰트는 번들 폰트와 같고 SubViewport 아래에서는 달랐다. 번들 폰트의 한글 표본은 존재한다. 픽셀 가독성과 Linux 수정 성공은 후속 렌더링으로 확인한다.

제품 흐름과 화면 구성은 유지한다. 두 코드 파일만 바꾼다.

- `src/ui/main.gd`: 실제 Main이 기존 `Ui.theme`을 명시적으로 사용한다.
- `tools/e2e/journey.gd`: 모든 캡처 직전에 표시된 Label과 Button의 실제 Font가 번들 Font인지, 표시할 한글 글리프가 있는지 검사한다. 시스템 fallback으로 가려진 문제도 실패로 기록한다.

새 폰트, 디자인, 저장 형식, 게임 규칙, 광고 정책과 플랫폼 SDK는 바꾸지 않는다. `project.godot`의 부팅 전 custom_font 설정은 ADR0003대로 사용하지 않는다. 기존 폰트와 라이선스를 유지하며 네트워크나 새 의존성이 없다.

## 책임과 실패 처리

폰트 선택은 실제 Main이 소유하고 테스트가 제품 테마를 주입해 통과시키지 않는다. 저장, 시계, 난수와 SDK 대체 경계 및 좌표 입력 도우미는 유지한다. 실패 단언과 원본 PNG를 보존하고 새로운 후보의 성공으로 예전 판정을 고쳐 쓰지 않는다.

중앙 과거 이력에는 최초1~3 결손, 완전4~9, 중단10과 완전 실패11을 실제 번호와 SHA, 시각, 판정, 해시 및 각 사전 승인으로 보존한다. 과거 중단10은 별도 형식이며 현재 후보 검수 수에는0회다. 현재 최종 후보의 독립 전체 검수3회, 최종 통과, 실제 실패 해결,168시간과 플랫폼 하한을 유지한다. 중앙 계약 보완은 별도 PR에서 검사와 코드 리뷰를 통과해야 한다.

## 적용, 운영과 복구

미출시 main 직접 반영 규칙을 따른다. 승인 설계, 두 코드 파일과 테스트 계획을 한 후보에 고정하고 이후 실행 기록은 소스 밖에 둔다. 실제 중앙 before-build 통과 전에 태그와 빌드 또는 업로드를 진행하지 않는다. 최종 versionName 기본값1.0.0과 원장 기준0은 기존 출시 승인대로 사용하고 할당 전 추측하지 않는다. 실제 광고 동의와 표시, Play Age Signals 동작을 개발 검사로 통과 처리하지 않는다.

수정 전 source archive와 과거 실패 원본은 저장소 밖에도 보존한다. 복구가 필요하면 실패 후보와 변경 범위를 먼저 확인하고 검증된 기존 파일을 근거로 처리한다. 사용자 저장과 `.serena/`는 보존한다.
