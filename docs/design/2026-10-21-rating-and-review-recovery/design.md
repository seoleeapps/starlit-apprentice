# 13세 대상 콘텐츠 수정과 검수 기록 복구

상태: 사용자가 직전 [후속 변경안](../../06-release/2026-10-21-launch-blockers.md)에 “승인한다”고 답했다. 승인을 기록한 시각은2026-10-21T10:53:24Z다. 이는 메시지 발신 시각을 소급 추정한 값이 아니다. 기존 Google Play 공개 출시 범위와 L3 개발 검수는 유지한다. 기기 사용, 추가 유료 생성과 IAM 권한 확대는 승인 범위가 아니다.

## 변경

기존 화면 구성, 아트와 안정된 이벤트 ID를 유지한다. `opp.wager-table`은 상인의 첫눈 예보 의뢰가 된다. 진입 비용과 골드 요건을 없애고 성공 사례금200을 지급한다. 실패 시 골드를 잃지 않는다. 지능 검사, 다른 성장 효과와 등장 조건을 유지한다.

`cond.burnout.enter`의 약 구매는 같은120골드의 식사와 휴식으로 바꾼다. `opp.plague-ward`는 물, 식량과 이불 지원으로 바꾸며 `world.guild-dispute`의 술 약속을 식사 약속으로 바꾼다. 한국어 원본과 ko/en 번역을 함께 바꾼다. 내부 플래그와 저장 형식은 유지하며 기존 저장을 초기화하지 않는다. 전체 확인에서 추가로 발견한 `milestone.s3.favorite`의 배당표는 예상 순위표로, `npc.rival.eden.05`의 내기는 금전이나 대가 없는 관측 경쟁으로 고친다. 두 이벤트의 수치와 ID는 유지한다. 약물, 음주와 도박 서술이 더 남는지 확인한다.

## 인수조건

- RC-01: 골드0에서도 예보 의뢰를 선택할 수 있고, 실제 코어 판정 성공은 순증200, 실패는 금전 손실0이다. 성공과 실패를 모두 결정론적으로 검증한다.
- RC-02: 바꾼 네 이벤트의 두 언어 서술에 판돈, 약 복용과 술 약속이 남지 않는다. 등장 조건, 기타 효과와 ID는 보존한다.
- RC-03: 기존 전체 회귀와 두 언어 화면 여정을 수행한다. 새로운 문구도 실제 화면에서 확인한다.
- RC-04: 결손 UI1/2를 소급 조작하지 않는다. 승인된 추가 검수 최대3회는 고정 SHA, 실행 전 계획과 시각, 독립 검수자, 격리 저장, 기능과 UX 근거를 갖춘다. 이전 실패 기록은 보존한다.
- RC-05: 수정된 실제 콘텐츠에 맞춰 IARC를 다시 작성하고 관측 등급과 저장 상태를 기록한다. 13세 대상과 여전히 충돌하면 멈춘다.

## 실행과 기록

기존 L3 테스트 계획을 이어받는다. RC-01은 요구사항 실패를 먼저 확인하고 데이터만 최소 수정한다. 번역 검사와 기존 밸런스/시뮬레이션을 실행한다. UI 추가 검수는 구현자와 다른 에이전트가 순차 진행하며 최대3회, 예상20분이다. 이번 승인 전 실행을 추가 검수로 재명명하지 않는다.

중앙 계약은 기존 회차 순번과 필수 소스/시각을 요구한다. 독립 계약 검토로 기존 허용 경로를 먼저 확인한다. 현재 계약으로 결손을 사실대로 표현하지 못하면 정식 보완 전 추가 검수를 시작하거나 before-build를 통과시키지 않는다. 변경된 중앙 검증 규칙이나 기록 양식은 제품 테스트 면제가 될 수 없다.

정적 검증을 통과한 제품 후보를 main에 반영하고 같은 SHA에서 CI와 승인된 개발 검수 근거를 모은다. 빌드/내부 업로드/심사/공개는 기존 원장의 미완료 조건을 각각 통과한 뒤 이어간다. WIF와 Android SDK는 아직 미확인이다.
